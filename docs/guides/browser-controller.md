# MIG Controller browser extension

[English](browser-controller.md) | [Français](browser-controller.fr.md)

**Control a web presentation with wrist movements**, using the browser extension
instead of desktop keyboard output. It targets Canva, Gamma, Google Slides and
PowerPoint web, with generic page keys for other accessible sites.

> [!IMPORTANT]
> **Experimental, unsigned packages.** Installed-extension tests cover controlled
> presentation pages. Rehearse with your real account and viewer before presenting.
> Some sites ignore simulated keys. Built-in PDF viewers and desktop applications
> are not supported by this extension.

1. Follow the [installation instructions](../../extensions/controller/README.md#build-and-install-for-testing).
2. Open your presentation and click the **MIG Controller** toolbar icon.
3. Check the target tab, then choose **Normal**, **Reversed** or import a profile.
   The diagrams show each gesture; **Change** records a different key.
4. Start the camera manually, or enable **Automatic** to follow presentation mode.
   Keep the controller window open. Allow camera access and keep both shoulders visible.
5. Make a wide sweep and return to rest. **Grey square: off. Red circle: camera active.**
   **Stop** also disables automatic mode; closing the window releases the camera.

> [!TIP]
> The **Studio link is above import**. Imported profiles show each movement and
> its key assignments. Use **Once** mode. Windows/Command, Alt and system shortcuts
> are refused; commands stay in the selected browser page.

See the [compatibility table](../../extensions/controller/README.md#detected-sites),
[test and store-review instructions](../../extensions/controller/README.md#validation-and-store-review)
and [privacy notice](../../extensions/controller/PRIVACY.md).
