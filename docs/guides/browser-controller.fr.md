# Extension navigateur MIG Controller

[English](browser-controller.md) | [Français](browser-controller.fr.md)

**Pilotez une présentation web avec les poignets**, via l'extension navigateur.
Elle cible Canva, Gamma, Google Slides et PowerPoint web, avec des touches
génériques pour les autres pages accessibles.

> [!IMPORTANT]
> **Paquets expérimentaux, non signés.** Les tests de l'extension installée couvrent
> des pages de présentation contrôlées. Répétez avec votre compte et votre lecteur
> réels avant de présenter. Certains sites ignorent les touches simulées. Les
> lecteurs PDF intégrés et les applications bureau ne sont pas pris en charge.

1. Suivez les [instructions d'installation](../../extensions/controller/README.fr.md#compiler-et-installer-pour-un-essai).
2. Ouvrez la présentation et cliquez sur l'icône **MIG Controller**.
3. Vérifiez l'onglet cible, puis choisissez **Normal**, **Inversé** ou importez un profil.
   Les schémas montrent chaque geste ; **Changer** enregistre une nouvelle touche.
4. Démarrez la caméra manuellement ou activez **Automatique** pour suivre le mode
   présentation. Gardez la fenêtre ouverte. Autorisez la caméra et gardez les épaules visibles.
5. Faites un geste ample puis revenez au repos. **Carré gris : arrêt. Rond rouge : caméra active.**
   **Arrêter** coupe aussi le mode automatique ; fermer la fenêtre libère la caméra.

> [!TIP]
> Le **lien du Studio est au-dessus de l'import**. Les profils importés affichent les
> mouvements et leurs touches. Utilisez le mode **Once**. Windows/Command, Alt et
> les raccourcis système sont refusés ; les commandes restent dans la page ciblée.

Consultez le [tableau de compatibilité](../../extensions/controller/README.fr.md#sites-détectés),
